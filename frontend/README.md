# HustleAI — Frontend Client

The web client for HustleAI, built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features
- Modern SaaS landing page with an interactive live product listing generator
- Unified dashboard with real-time business statistics and quick-action tool launchers
- 5 AI business assistants (Smart Listing Writer, Invoice Studio, Receipts OCR, Marketing Copy, Business Emails)
- Real-time ReportLab PDF invoice generation
- Transparent model configuration & privacy mode switcher (Local Air-Gapped vs Remote API)
- Dark and light theme modes

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build
```
